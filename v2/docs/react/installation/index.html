Installation

npm i @cuple/react

Requires React 19 and @cuple/client.

Setup​

Create a store next to your client:

export const client = createClient<typeof routes>({ path: "/rpc" });
export const store = createCupleStore();

Provide it once, at the root, with a <Boundary> around what loads:

export function App() {
  return (
    <CupleProvider store={store}>
      <Boundary
        fallback={<TodoListSkeleton />}
        error={(error, retry) => (
          <p>
            {error.message}{" "}
            <button type="button" onClick={retry}>
              Retry
            </button>
          </p>
        )}
      >
        <TodoList />
      </Boundary>
    </CupleProvider>
  );
}

<Boundary> shows its fallback while anything inside it loads, and its error when something inside it fails.

That's all. Read data with useGet, and change it with useAction.

Why it works this way
  • A store you create, not a hidden global. Sign-in, an SSE handler and a router loader aren't components, but they need to refresh or clear data. They use the same store the hooks use, and each test can start from a fresh one.

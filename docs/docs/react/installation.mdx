# Installation

```bash
npm i @cuple/react
```

Requires React 19 and `@cuple/client`.

## Setup

Create a store next to your client:

```ts file=../../../examples/docs/todos/client.ts#setup
```

Provide it once, at the root, with a `<Boundary>` around what loads:

```tsx file=../../../examples/docs/todos/app.tsx#setup
```

`<Boundary>` shows its `fallback` while anything inside it loads, and its `error` when something inside it fails.

That's all. Read data with [`useGet`](./reading), and change it with [`useAction`](./actions).

To run this todo app: `cd examples/docs && npm run dev:todos`.
